# GSAP skills — source and license

The `gsap-*` folders in this directory are unmodified copies of GreenSock's
official agent skills.

- Source: https://github.com/greensock/gsap-skills (`skills/` folder)
- Commit: `aed9cfd3277740755f6bfc1155c7aa645403b760` (2026-04-21)
- Skills: `gsap-core`, `gsap-timeline`, `gsap-scrolltrigger`, `gsap-plugins`,
  `gsap-utils`, `gsap-react`, `gsap-performance`, `gsap-frameworks`

To update, replace each `gsap-*/SKILL.md` with the newer file from the source
repository and change the commit above.

The GSAP library itself is a separate project
(https://github.com/greensock/GSAP) under GreenSock's own license; it is not
included here. Add it to a project with `npm install gsap` or the CDN script.
